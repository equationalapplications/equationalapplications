## Products

### [Clanker](https://equationalapplications.com/products/clanker/) — Personal AI Companion

Talk to your custom AI character in real time, just like a phone call — with a memory that never forgets.

- **Real-time voice** — speak naturally via Gemini Live; interrupt mid-sentence, hands-free on echo-cancelled speakerphone
- **Memory that never forgets** — LLM Wiki persistent memory learns your context across every conversation
- **Custom companions** — design your own AI character with a unique personality
- **Smart capabilities** — upload PDFs, Word docs, and images; search the live web; browser bridge and edge agent tools
- **Private & secure** — processed through Google Vertex AI, never used to train foundation models

**Stack**: React Native · Expo · TypeScript · Vertex AI · Gemini Live · Firebase · Cloud SQL · Stripe · xState

[clanker-ai.com](https://clanker-ai.com) · [Real-Time Voice](https://clanker-ai.com/real-time-voice) · [GitHub](https://github.com/equationalapplications/clanker) · [App Store](https://apps.apple.com/us/app/clanker-ai/id6754219831) · [Google Play](https://play.google.com/store/apps/details?id=com.equationalapplications.clanker)

### [LLM Wiki Memory](https://equationalapplications.com/products/memory/) — Agentic Memory Platform

Platform-agnostic TypeScript engine for hybrid LLM memory. Episodic fact extraction, vector search, ontology graphs, and multi-agent architectures over SQLite. Powers Clanker and available on npm.

| Package | Audience |
|---------|----------|
| [`@equationalapplications/core-llm-wiki`](https://www.npmjs.com/package/@equationalapplications/core-llm-wiki) | Any runtime with SQLite |
| [`@equationalapplications/expo-llm-wiki`](https://www.npmjs.com/package/@equationalapplications/expo-llm-wiki) | React Native / Expo |
| [`@equationalapplications/react-llm-wiki`](https://www.npmjs.com/package/@equationalapplications/react-llm-wiki) | React web |
| [`@equationalapplications/core-llm-tools`](https://www.npmjs.com/package/@equationalapplications/core-llm-tools) | Agent tool definitions & permissions |

[Product Page](https://equationalapplications.com/products/memory/) · [GitHub](https://github.com/equationalapplications/expo-llm-wiki)
